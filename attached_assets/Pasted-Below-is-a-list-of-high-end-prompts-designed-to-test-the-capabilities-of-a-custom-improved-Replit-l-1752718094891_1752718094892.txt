Below is a list of high-end prompts designed to test the capabilities of a custom, improved Replit-like AI with advanced features such as pulling saved credentials, automatic account login, account creation, API management, self-learning, and content AI-powered improvements. These prompts are structured to evaluate the AI's functionality, security, adaptability, and intelligence across various scenarios.
1. Credential Management and Automatic Login
Prompt:
"Using securely stored credentials from my profile, log in to my GitHub account and retrieve the list of my public repositories. If the credentials are outdated or missing, prompt me to update or input them securely, then save them for future use. Ensure all interactions with credentials are encrypted and follow best security practices."
Purpose: Tests secure credential storage, retrieval, automatic login, and error handling for outdated credentials.
2. Account Creation and API Integration
Prompt:
"Create a new account on a specified platform (e.g., GitLab) using a randomly generated email and a strong password. Save the credentials securely in my profile. Then, generate an API token for the new account, store it securely, and use it to create a new private repository named 'TestRepo' via the platform’s API. Provide a confirmation of the repository creation and the saved API token details (without exposing the token)."
Purpose: Evaluates account creation, secure credential storage, API token generation, and programmatic interaction with third-party APIs.
3. API Search and Integration
Prompt:
"Search for a public API that provides real-time weather data. Select the most reliable option based on documentation quality and uptime. Create a Python script that integrates this API into a simple weather app, automatically handling authentication if required. Save the API details and the script in my project workspace for future use."
Purpose: Tests the AI’s ability to search for APIs, evaluate their quality, integrate them into code, and save relevant data.
4. Self-Learning and Code Improvement
Prompt:
"Analyze my recent Python project on Replit that implements a to-do list app. Identify inefficiencies or bugs in the code, suggest improvements based on best practices, and implement them after my approval. Use self-learning to adapt your suggestions to my coding style (e.g., prefer concise functions or specific naming conventions) based on my past projects. Provide a detailed explanation of the changes and their benefits."
Purpose: Tests self-learning capabilities, code analysis, and tailored improvement suggestions.
5. Content AI-Powered Documentation
Prompt:
"Generate comprehensive documentation for a Node.js project I’ve built in the workspace, which includes a REST API for a blog platform. Use content AI to create clear, user-friendly documentation with examples, automatically inferring the project’s structure and endpoints. Save the documentation as a Markdown file in my workspace and suggest improvements to make the API more user-friendly."
Purpose: Tests the AI’s ability to generate high-quality documentation, infer project details, and provide UX-focused suggestions.
6. Automated Testing and Debugging

Identify any bugs or performance issues, fix them, and provide a report summarizing the test results and fixes applied. Save the test suite for future use."
Purpose: Evaluates test generation, debugging, and reporting capabilities.
7. API Creation and Deployment
Prompt:

Generate and save an API key for accessing the deployed API, and provide a cURL command to test the /notes endpoint. Ensure the deployment is secure and follows best practices."
Purpose: Tests API creation, deployment automation, credential usage, and secure key management.
8. Cross-Platform Integration and Workflow Automation

"Set up a CI/CD pipeline for my Python project in the workspace using GitHub Actions. Automatically log in to my GitHub account using stored credentials, create a new repository, push the project to it, and configure the pipeline to run tests and deploy to a specified cloud platform (e.g., AWS) on every push. Save the pipeline configuration and provide a summary of the setup."
Purpose: Tests integration with external platforms, automation of complex workflows, and secure credential handling.
